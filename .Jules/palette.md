## 2026-09-06 - ARIA attributes on icon-only buttons
**Learning:** In this application, several modal close buttons (`.close-button` with `&times;`) and delete buttons (`.btn-del` with `×`) were lacking `type="button"` and basic accessibility attributes like `aria-label` and `title`. Because the application is predominantly in Polish, we must use Polish translations like "Zamknij" and "Usuń wpis" to provide an accessible and intuitive user experience.
**Action:** Always ensure that icon-only interactive elements contain `type="button"` and meaningful, localized `aria-label` and `title` attributes (e.g. `aria-label="Zamknij"`, `title="Zamknij"` for close buttons). This prevents form submissions, allows screen readers to correctly read the button intent, and adds hover tooltips for sighted users.
